# TallyLights

Самостоятельное Windows-приложение: **Blackmagic ATEM → AVMATRIX TS3019-6**
по USB/COM, протокол Firmata. Для обычной работы браузер и консоль не нужны.

## Запуск окна

Скачайте **TallyLights_V0.3.1.exe** со страницы
[Releases](https://github.com/Knyazzer/TallyLights/releases/latest) и запустите
двойным щелчком. Windows 10/11 x64; устанавливать Node.js или открывать консоль
не нужно. Это нативное окно WinForms (.NET Framework 4.8), не Electron.

EXE содержит Node.js 24 LTS и все зависимости. При запуске runtime извлекается
во временный каталог и удаляется при нормальном выходе. Настройки и журнал
остаются в `TallyLights-data` рядом с EXE. Держите приложение в папке с правом
записи. Перед обновлением завершите приложение через меню трея, затем замените
EXE и сохраните папку данных. Если переносите
приложение на другой компьютер вместе с настройками, перенесите и эту папку.

Для пересборки из исходников (Windows x64, Node.js с npm, .NET Framework 4.8):

```powershell
npm ci
npm run build:portable
npm run test:desktop
npm run test:portable
```

Результат: `dist/portable/TallyLights_V0.3.1.exe`. Контрольная сумма
`SHA256SUMS.txt` создаётся локально для проверки сборки и не публикуется в релизе.
Первый запуск сборки скачивает официальный Node.js, проверяет SHA-256 из
`build/runtime.json` и кэширует его в `.portable-build`. Дальнейшие сборки
используют кэш. В EXE не попадают конфиги, журналы или демонстрационные устройства.
`npm run build:desktop` оставлен для разработки многокомпонентной сборки;
Inno Setup — дополнительный вариант, `npm run build:installer`.

Окно содержит три вкладки:
- **Настройки** — поиск ATEM с названиями, выбор устройства или ввод IP,
  автоматический/ручной COM-порт, скорость (57600 по умолчанию), Clear/Hold.
- **Маппинг** — назначение входа ATEM с его названием каждой лампе.
  Изменения сохраняются сразу.
- **Тесты** — отдельные секундные импульсы Program/Preview.
  После импульса восстанавливается последнее живое состояние ATEM.

Визуальная компоновка следует ATEM Software Control: ряды Program/Preview слева,
постоянная палитра подключений справа и нижняя навигация. Подробности:
[визуальная архитектура](docs/atem-visual-design.md).

Состояния подключений и шести ламп видны на всех вкладках.
Закрытие/сворачивание окна оставляет сервер в трее. Двойной щелчок по значку
или повторный запуск EXE возвращают окно. «Завершить процесс» в меню трея
завершает сервер и гасит лампы.
Windows Job Object завершает дочерний сервер также при аварийном закрытии окна.
Для сценариев обслуживания `TallyLights_V0.3.1.exe --exit` корректно завершает
экземпляр из той же папки. Версия видна в заголовке окна, трее и свойствах EXE.

## Подключения

Сервер запускается без оборудования. COM-порты проверяются в фоне каждые две
секунды; при отключении USB выполняется повторное подключение. Смена COM-порта
и скорости не требует перезапуска. После восстановления порта отправляется
актуальное состояние ламп.

Автопоиск рассматривает устройства AVMATRIX и USB-адаптеры CH340
(VID 1A86, PID 7523/5523). Если кандидатов несколько, нужно выбрать COM-порт.
Другие устройства автоматически не открываются. CH340 используется и в другом
оборудовании, поэтому это только кандидат, а не подтверждённая модель.

AVMATRIX не отвечает на Firmata-handshake. Статус **«порт открыт»** подтверждает
открытие serial-транспорта, но не получение команды боксом. Проверяйте физические
лампы кнопками тестирования. Используются сырые SET_PIN_MODE / DIGITAL_MESSAGE
без ожидания ответа от прошивки.

ATEM автоматически ищется, если IP не задан. При единственном найденном пульте
он выбирается и запоминается; если пультов несколько — выбор во вкладке настроек.
Выбранный IP не заменяется другим пультом при потере связи. Библиотека
atem-connection переподключается к выбранному адресу. Поиск повторяется каждые
15 секунд, пока IP не выбран. Сканируется локальный /24-сегмент каждого IPv4
интерфейса, UDP 9910; для других сегментов используйте ручной IP.

В настройках ATEM выбирается M/E для Program/Preview. Доступные M/E берутся
из возможностей подключённого пульта; по умолчанию используется M/E 1. Выбор
применяется без перезапуска и переподключения. Кейеры и DSK пока не учитываются. При потере ATEM по умолчанию **Clear** гасит лампы; **Hold**
сохраняет последнее состояние. Явно сохранённый Hold из прежнего конфига
сохраняется при миграции.

## Данные и настройки

Оконная сборка хранит `TallyLights-data/config.json` и `server.log` рядом с EXE.
Маппинг, IP и M/E, COM-порт, скорость и Clear/Hold записываются атомарно при
применении и восстанавливаются после полного выхода и повторного запуска.
Локальные настройки из рабочего checkout в сборку не копируются.
Старое поле `defaultMode` автоматически игнорируется и удаляется при сохранении.
Отдельного ручного режима больше нет. Пины шести ламп заданы в `src/lampPins.js`.

HTTP-порт оконной версии выбирается ОС автоматически и не настраивается
пользователем. Сервис слушает только 127.0.0.1.
Для разработки остаётся `npm start` (сервер без окна, порт из config.json,
по умолчанию 8080) и веб-интерфейс на этом адресе.
`TALLY_DATA_DIR` переопределяет каталог настроек.

## API и проверка

- `GET /status` — лампы, тестовые переопределения, подключения и входы ATEM.
- `GET /events` — SSE тех же данных, включая отдельные изменения подключений.
- `GET /api/config`, `PATCH/PUT /api/config` — настройки, частичные обновления.
- `GET /api/ports`, `GET /api/atem/scan`, `GET /api/atem/inputs`.
- `POST /api/serial/reconnect` — немедленная попытка подключения.
- `POST /api/test/lamp/:id?color=program|preview` — секундный импульс.
- `POST /api/test/stop` — закончить все тесты.

Команды прежнего ручного управления и маршруты мониторинга внешнего лаунчера
удалены. Отдельного внешнего менеджера процессов для работы приложения не нужно.

```powershell
npm test
npm run test:desktop
npm run test:portable
```

Тесты используют подмену COM, ATEM и UDP; физическое оборудование не требуется.
Проверки WinForms выполняются отдельно: собственные меню, мышь/клавиатура,
Escape, поиск по буквам, прокрутка, недоступность M/E без подключения и
стабильная геометрия навигации при выполнении операций и изменении размера окна.
Проверка portable запускает настоящий EXE дважды с изолированными настройками,
проверяет нативную serial-библиотеку, single instance, восстановление маппинга
и параметров, завершение сервера и удаление временного runtime. Реальные COM-порты
в этой проверке не открываются. Тестовые данные остаются в `.portable-build/smoke-*`.
Смена HTTP-порта/включения HTTP в серверном режиме требует перезапуска;
остальные настройки применяются на лету.
