# История изменений

## 0.3.1 — 2026-10-31

- Собственные тёмные выпадающие меню WinForms вместо системных ComboBox,
  с мышью, клавиатурой, Escape, поиском по буквам и прокруткой длинных списков.
- Неактивный M/E отображается приглушённым без выделения, пока ATEM не подключён.
- Удалена нижняя строка операций: прогресс сканирования находится в кнопке,
  навигация и рабочая область не меняют положение при действиях.
- Добавлена буферизация контейнеров и всей формы для корректной перерисовки при resize.
- Рамка рабочей области вынесена за прокручиваемые вкладки и не перекрывается их содержимым.
- Во внутренней шапке только «Tally Lights»; иконка и версия остаются в заголовке окна.
- В GitHub Release публикуется только EXE, без отдельного SHA256SUMS.txt.
- 30 проверок собственных WinForms-контролов, геометрии и полного периметра рамки,
  дополнительно к 84 тестам backend.

## 0.3.0 — 2026-10-31

- Один портативный Windows x64 EXE со встроенным Node.js 24.22.2 LTS и зависимостями.
- Новый значок лампы с Program/Preview для приложения, окна и трея; векторный логотип.
- Версия в имени EXE, заголовке, трее и свойствах Windows; единый источник версии.
- Восстановление нативного окна из трея и при повторном запуске, без браузера.
- Убраны дублирующие кнопки выхода/сворачивания и постоянная нижняя подсказка;
  полное завершение — пункт «Завершить процесс» в меню трея.
- Постоянные настройки рядом с EXE; проверка сохранения маппинга и параметров
  после полного перезапуска портативной сборки.
- Проверка нативной serial-библиотеки, single instance и очистки временного runtime.

## 0.2.0 — 2026-10-31

- Самостоятельное окно WinForms с треем; скрытый сервер и управление его жизненным циклом.
- Удалены интеграция Watchdog, старый systray и отдельное ручное управление.
- Автоматическое подключение и восстановление USB/COM без перезапуска сервера.
- Поиск ATEM с названием устройства, выбор IP и доступного M/E.
- Три вкладки: настройки, маппинг и тесты; постоянный монитор Program/Preview.
- Современные тёмные элементы, компактный маппинг по центру и собственные выпадающие меню.
- Clear по умолчанию, Hold по выбору; тестовые импульсы с возвратом к сигналу ATEM.
- 84 автоматические проверки логики, API, конфигурации и соединений.
