# Визуальная архитектура TallyLights

Тёмная операторская панель с компоновкой ATEM Software Control:
монитор слева сверху, рабочие разделы под ним, соединения справа, навигация снизу.
Поверхности плоские, без металлического рельефа, градиентных клавиш и светотеневых
фасок. Акцент навигации — янтарный; Program — красный; Preview — зелёный.

## Компоновка

| Зона | Содержимое |
| --- | --- |
| Верхняя полоса | TallyLights Software Control |
| Tally Monitor | Два ряда по шесть индикаторов, с названием источника |
| Настройки | ATEM, IP/поиск, выбор M/E; COM, скорость, Clear/Hold |
| Маппинг | Один компактный столбец по центру, в списке номер входа и название с ATEM |
| Тесты | Program и Preview; нажатие даёт импульс с автоматическим восстановлением |
| Правая палитра | Только соединения ATEM и AVMATRIX, выбранный M/E |
| Нижняя навигация | Настройки, Маппинг, Тесты |

Настройки не растягивают поля на всю ширину панели. COM — около 260–280 px,
маппинг — около 210 px, M/E и скорость — около 140 px.
Правый блок не дублирует состояния ламп. В тестах нет кнопки завершения,
подписей цветов и текста о длительности импульса.

## Выбор M/E

Конфигурация хранит `atem.me` — номер начиная с 1, по умолчанию 1.
Список доступных шин строится по `state.info.capabilities.mixEffects` пульта;
при отсутствии этой информации используется полученный массив M/E.
Выбор применяется на лету без переподключения ATEM. Читаются Program/Preview
выбранной шины. Если сохранённая шина отсутствует у нового пульта, она отмечается
как недоступная; данные другой шины вместо неё не подставляются.

В маппинге используются входной номер и `longName` пульта, с резервом на
`shortName`. Дополнительный префикс CAM не генерируется. Если само название,
заданное на пульте, содержит CAM, оно сохраняется без исправлений.

## Палитра

| Элемент | Цвет |
| --- | --- |
| Рабочее поле | #191A1C |
| Панели | #232527 |
| Поля | #1A1B1E |
| Равномерная рамка | #383B40 |
| Основной текст | #EDF0F2 |
| Вторичный текст | #A2A7AE |
| Навигация/фокус | #E4A342 |
| Program | #ED5964 |
| Preview | #54CE91 |

Активные индикаторы имеют приглушённую красную/зелёную заливку, светлый текст и
тонкую цветную рамку. Неактивные — тёмные. Тест отмечается небольшой янтарной
точкой. Веб-интерфейс и нативное окно используют одинаковые роли цветов.

## Исходники

- `desktop/ConsoleTheme.cs` — палитра и рисуемые контролы окна.
- `desktop/Program.cs` — компоновка и привязка состояния API.
- `public/index.html`, `public/styles.css` — веб-интерфейс.
- `public/app.js` — списки, индикация, выбор M/E и тесты.
- `src/sources/atemSource.js` — возможности ATEM и tally выбранного M/E.

- [Общая панель Switcher](https://images.blackmagicdesign.com/images/products/atemconstellation/software-control/switcher/main/switcher-main-en-lg.jpg?_v=1734474616).

Визуальный стенд использует подмену ATEM/COM и пример пульта с двумя M/E.
Тестовые данные не встраиваются в обычную сборку.

Веб-списки используют собственные всплывающие меню в цветах панели.
Раскрытие мышью не добавляет яркую рамку. Клавиатурный фокус отмечен
подчёркиванием текста; доступны стрелки, Enter, Escape, Home/End и поиск набором.
