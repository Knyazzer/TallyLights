Исправления интерфейса портативного Tally Lights после v0.3.0.

Скачайте **TallyLights_V0.3.1.exe**. Перед обновлением выберите «Завершить процесс» в трее, затем запустите новый EXE. Сохраните папку **TallyLights-data** рядом с EXE — в ней маппинг и остальные настройки.

### Исправлено

- Выпадающие меню COM, скорости, Clear/Hold, M/E и маппинга полностью перерисованы в тёмном стиле приложения. Системные ComboBox с синей/белой рамкой больше не используются.
- M/E приглушён и не раскрывается без подключённого ATEM. Доступность корректно восстанавливается после сохранения и меняется при потере связи.
- Убрана нижняя строка операций, из-за которой прыгала навигация. При сканировании надпись меняется внутри кнопки; результат показывается в блоке ATEM.
- Добавлена буферизация перерисовки формы и контейнеров при изменении размера окна.
- Исправлена неполная рамка рабочей области: вкладки находятся внутри общей рамки и не перекрывают её.
- Внутренняя шапка содержит только **Tally Lights**. Иконка и версия находятся в системном заголовке; текст Software Control убран.
- В релизе оставлен один EXE. SHA256SUMS.txt не требуется для запуска и больше не публикуется.

### Проверено

84 теста приложения, 30 проверок WinForms-контролов и компоновки, запуск реального portable EXE, single instance, нативный SerialPort и сохранение настроек после полного перезапуска. Полный периметр рамки проверен по пикселям на трёх вкладках и трёх размерах окна. В нативном интерфейсе проверены выбор мышью, клавиатурное переключение M/E, изменение размера и оформление меню.

Windows 10/11 x64, .NET Framework 4.8. Node.js включён в EXE. Проверки выполнены без физического ATEM/AVMATRIX.

Приложение пока не подписано сертификатом издателя, поэтому Windows SmartScreen может предупреждать при первом запуске. Подпись и репутация настраиваются отдельно; [Microsoft объясняет поведение SmartScreen](https://learn.microsoft.com/windows/apps/package-and-deploy/smartscreen-reputation).
