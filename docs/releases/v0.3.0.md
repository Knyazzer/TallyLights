TallyLights — портативное приложение для передачи Program/Preview из Blackmagic ATEM на AVMATRIX TS3019-6 по USB/COM.

### Скачать и запустить

Скачайте **TallyLights_V0.3.0.exe** из файлов ниже и запустите двойным щелчком.
Windows 10/11 x64, .NET Framework 4.8. Устанавливать Node.js и запускать `npm start` не требуется.

Это **нативное окно WinForms**, не Electron и не браузер. EXE включает Node.js 24.22.2 LTS и production-зависимости, в том числе нативный SerialPort.

### Что изменилось

- Три вкладки: настройки подключений, маппинг и тесты. Монитор Program/Preview всегда виден.
- Автоподключение USB/COM и восстановление после отключения без перезапуска сервера.
- Поиск ATEM с названиями, ручной IP, выбор доступного M/E.
- Компактный маппинг, тёмные элементы управления и новый логотип лампы с цветами Program/Preview.
- Значок встроен в EXE, окно и трей. Версия указана в заголовке, трее, свойствах и имени файла.
- Крестик сворачивает окно в трей; двойной щелчок по значку или «Открыть TallyLights» возвращает окно. Полный выход — «Завершить процесс» в меню трея.
- Удалены Watchdog-интеграция, старый systray и отдельное ручное управление.

### Настройки и обновление

Маппинг, IP/M/E, COM, скорость и Clear/Hold автоматически сохраняются в **TallyLights-data/config.json** рядом с EXE. Журнал — в той же папке. При обновлении замените EXE, сохранив `TallyLights-data`. Каталог приложения должен быть доступен для записи.

По умолчанию скорость — **57600 бод**, при потере ATEM — **Clear**. «Порт открыт» подтверждает serial-соединение; получение сигнала AVMATRIX проверяется физическими лампами во вкладке тестов.

### Проверка релиза

- 84 автоматических теста приложения.
- Реальный портативный EXE: запуск без внешнего Node, нативная serial-библиотека, один экземпляр, версия окна.
- Изменение и восстановление всех шести назначений и параметров после полного перезапуска.
- Корректный выход, в том числе во время запуска, и очистка временного runtime.
- Визуальная проверка окна, логотипа и возврата из трея повторным запуском.

Проверки сборки выполнены без физического ATEM/AVMATRIX. Файл не подписан сертификатом издателя.
